# UI consistency research

Checked 2026-09-10. Primary sources were searched and opened; appearance choices below are AutoAssist decisions, not claims of a universal current fashion.

- [Design Tokens Community Group technical reports](https://www.designtokens.org/technical-reports/): the stable 2025.10 format supports sharing named design decisions between tools. Adopt named values and one owner. A CSS-only prototype does not need an exchange-format compiler or a full token platform.
- [Adobe Spectrum design data](https://opensource.adobe.com/spectrum-design-data/tokens/): distinguishes palette values, semantic aliases, component colors, typography, and layout. Adopt a small semantic set for surfaces/text/actions/focus/status and a shared geometric scale; do not reproduce its enterprise catalog. The older Spectrum overview returned a JavaScript shell, so this retrieved primary data documentation supplies the evidence.
- [Carbon chatbot usage](https://carbondesignsystem.com/community/patterns/chatbot/usage/): separates header, messages, composer, structured responses, and informative cards and asks the bot to communicate its role. Adopt a consistent component vocabulary and clear AI identity. Do not copy IBM's palette, obligatory close control, faded prior messages, or human-handoff/feedback features into this API-first prototype.
- [assistant-ui Composer](https://www.assistant-ui.com/docs/primitives/composer): its primitives allow custom elements/classes while retaining runtime behavior. Use the accepted library with scoped plain CSS. Tutorial utility classes and extra controls are not dependency or product requirements. Verify the installed version at implementation.
- [WCAG text contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) and [non-text contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html): verify real foreground/background combinations and required visual control cues, not the attractiveness of a palette. Text targets are 4.5:1 normally and 3:1 for qualifying large text; necessary control/state cues need 3:1. A token check alone is not a full accessibility audit.
- [WCAG target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) and [reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html): AA target sizing has a 24px minimum with defined spacing/exceptions; AutoAssist deliberately uses a roomier 44px control default. Check narrow reflow rather than hiding overflow. Browser rendering and actual interaction remain necessary.

Synthesis: agents need named values, component/state intent, a concrete rendered reference, selective routing, and evidence for changes. “Make it professional” alone leaves those decisions open on every task. We choose graphite chrome, light reading surfaces, teal accents, system fonts, restrained geometry, and no added theme dependency. Skill workflow, token values, and visual reference have distinct purposes; the token file is the sole editable source of exact shared values.
