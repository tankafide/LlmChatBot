# NHTSA integration research

Checked 2026-09-10 (America/Chicago). Sources are upstream facts; service boundaries, result-state design, budgets, and fake-based CI are AutoAssist implementation decisions. No application code or tests exist as a result of this skill authoring.

- [NHTSA datasets and APIs](https://www.nhtsa.gov/nhtsa-datasets-and-apis): recall lookup is `GET https://api.nhtsa.gov/recalls/recallsByVehicle` with `make`, `model`, `modelYear`; ratings use `/SafetyRatings/modelyear/{year}/make/{make}/model/{model}` then `/SafetyRatings/VehicleId/{id}`. Parameter/method casing matters. This prevents borrowing the wrong variant's rating.
- [Live variant example](https://api.nhtsa.gov/SafetyRatings/modelyear/2013/make/Acura/model/rdx) returned FWD and 4WD alternatives; [detail example](https://api.nhtsa.gov/SafetyRatings/VehicleId/7520) returned `Not Rated` strings. The [recall example](https://api.nhtsa.gov/recalls/recallsByVehicle?make=acura&model=rdx&modelYear=2012) uses lowercase `results`, whereas ratings use `Results`. Build endpoint-specific boundary validation, not one permissive dictionary parser. Samples are observations, not immutable fixtures or assignment inventory.
- [NHTSA ratings explanations](https://www.nhtsa.gov/ratings): unrated categories have not been tested for that condition; overall/frontal comparison requires the same class and weights within 250 pounds. High star ratings may coexist with a safety concern. Preserve these limits instead of generating a universal safety ranking.
- [NHTSA recall search](https://www.nhtsa.gov/recalls): model lookup and VIN recall lookup have different scope. Do not infer individual repair status from model campaigns or present an empty result as a safety guarantee.
- [HTTPX async lifecycle](https://www.python-httpx.org/async/) advises client reuse for pooling and explicit closure. [Timeouts](https://www.python-httpx.org/advanced/timeouts/) distinguish connect/read/write/pool waits; [resource limits](https://www.python-httpx.org/advanced/resource-limits/) bound pooled connections. AutoAssist additionally budgets the whole lookup and chat run so several individually bounded operations cannot overrun the user request.
- [HTTPX transports](https://www.python-httpx.org/advanced/transports/) supports MockTransport for deterministic requests and responses. Use it to verify aliases, URL parameters, error mapping, and retries; use service fakes at the chat boundary. This separates transport correctness from model wording and live availability.

Recheck concrete payloads and compatibility during implementation. The current source samples verify the documented lookup flow, not uptime guarantees or a published service quota; choose bounded local limits explicitly rather than inventing NHTSA limits.
