Agent failure to prevent: assuming a synchronous repository call inside async orchestration uses a thread automatically. Require a traced offload boundary and responsiveness evidence.

Application-level transaction framing supports repository composition. Project application: inject a factory and offload the whole synchronous unit, returning materialized application records.
- [HTTPX async support](https://www.python-httpx.org/async/): reuse scoped async clients to retain connection pooling and close them deliberately. Project application: construct/inject clients in lifespan, avoiding client construction inside tool loops and hidden globals.
- [Pydantic AI message history](https://pydantic.dev/docs/ai/core-concepts/message-history/): supported adapters serialize and reload model history. Project application: preserve full internal replay data while preventing library serialization from becoming the public API contract; browser-submitted data cannot replace server-owned history.
