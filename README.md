# AutoAssist

An LLM-powered dealership chatbot prototype for the Mia Labs take-home interview.

## Required capabilities
- HTTP API accepting text messages and returning text replies.
- Relational-database inventory search and follow-up questions about specific vehicles.
- NHTSA recalls and crash-test ratings.
- Persisted conversations and messages that survive server restarts.

## Current status
Repository and project context initialized. Application implementation has not started, and the assignment's inventory attachment has not yet been provided. No application tests are available yet.

## Project organization
- `AGENTS.md`: focused instructions for AI-assisted implementation.
- `prompt history/`: timestamped user prompts for the interview walkthrough.
- `docs/plans/`: implementation plans and design decisions.
